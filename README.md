# Nafuda 名札

**Every slab wears its name.** Graded trading-card slabs get an ENSv2 name — a transferable title bound to the slab's chip — so buyers can verify both *which physical slab* and *who owns it* on the spot.

> Built at ETHGlobal Tokyo 2026 (ENSv2 track). Work in progress.

> PSA-Sim is a simulated grader modeled after PSA's certification format and flow. It is not affiliated with or endorsed by PSA (Professional Sports Authenticator).
